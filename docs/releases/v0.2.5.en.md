# Coopanion v0.2.5

**Focus can carry a goal and pause at any time; official releases are announced, never installed**

## New

- **Focus goals**: pick an existing goal before a focus stretch starts, or add, rename and delete goals on the Study page. Goals have their own colours, and history keeps the name a deleted goal had.
- **Pause and resume**: pause a stretch to stop both the clock and supervision; resuming continues the same stretch, and the pause is not counted.
- **Pet menu**: the pet's right-click menu lists goals to start toward while idle, shows the current goal during a stretch, and offers pause, resume and stop.
- **Stats by goal**: filter the stats by one goal and see each goal's time and share; the session table gains a goal column.
- **Coo can do it too**: telling Coo to start, pause, resume or end focus calls the matching tool; a goal named at the start is recorded on that goal.

## Changes

- **Official releases are only announced**: when a newer official version is found, Coo's bubble and the settings version line link to the GitHub release, and nothing is downloaded or installed. This build is upgraded by merging upstream and rebuilding.
- Merged every official v0.2.4 change, including multi-display computer use, region zoom, input bubbles and the bubble-size setting.

This version is a local build; no public installer is provided.
