# Coopanion v0.2.5

**专注可以带目标、随时暂停；官方更新只提示，不再自动安装**

## 新功能

- **专注目标**:专注开始前可以从已有目标里选一个，也可以到「学习」页新增、重命名、删除目标。目标按颜色区分，删除后历史记录仍保留当时的名称。
- **暂停与继续**:专注中可以暂停，计时和监督一起停下；继续后同一段专注接着计，暂停的时间不算。
- **桌宠菜单**:右键菜单空闲时列出可开始的目标，专注中显示当前目标，并可暂停、继续或停止。
- **按目标统计**:统计区可以只看某个目标，并列出每个目标的时长和占比；记录表新增目标列。
- **Coo 也能控制**:对 Coo 说开始、暂停、继续或结束专注时，它会调用对应工具；开始时说了目标名就记到该目标上。

## 改动

- **官方更新只提示**:查到官方新版本时，Coo 的气泡和设置页版本行给出 GitHub 下载链接，不下载、不安装。这个自用版本升级仍靠合并官方代码后重新打包。
- 合并官方 v0.2.4 的全部改动，包括多显示器电脑操作、局部放大、输入气泡和气泡尺寸设置。

本版本是本地构建，不提供公开安装包。
